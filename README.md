# Hola 计算器

一款基于 HarmonyOS 的万能计算器应用，集成日常计算、单位换算、个税估算和房贷计算等实用功能。

## 功能特性

### 基础计算器
- 加、减、乘、除四则运算
- 百分比计算
- 支持小数点与退格删除
- 运算符优先级处理

### 单位换算
- **长度**：毫米、厘米、米、千米、英寸、英尺、码、英里
- **体积**：毫升、升、立方厘米、立方米、加仑
- **时间**：秒、分钟、小时、天、周、月、年
- **重量**：毫克、克、千克、吨、盎司、磅
- **面积**：平方毫米、平方厘米、平方米、亩、公顷、平方千米、平方英尺

### 秒表
- 毫秒级精度计时
- 开始 / 暂停 / 重置
- 多次计次记录

### 个税估算
- 基于中国大陆综合所得年度口径
- 支持调整起征点（默认 5000 元/月）
- 社保与公积金支持按比例或固定额度扣除
- 7 项专项附加扣除（子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、婴幼儿照护）
- 月度扣税明细与税后到手工资一览

### 房贷计算
- 支持商业贷款、公积金贷款、组合贷
- 等额本息 / 等额本金两种还款方式
- 组合贷可分别设置两部分年限与利率
- 显示月供、总利息、总还款等关键指标

### 分类编辑
- 顶部标签栏支持自定义排序
- 通过「编辑」入口调整计算器分类顺序

## 开发环境

- DevEco Studio 5.0+
- HarmonyOS SDK (API 12+)
- hvigor 构建工具

## 构建与运行

1. 使用 DevEco Studio 打开项目根目录
2. 等待 hvigor 同步依赖
3. 选择目标设备（手机或平板）后点击 Run
