## 「万能计算器」—— 一个 App 顶七个

我们做了一款真正「万能」的计算器，把日常所有计算场景全部整合在一起。不臃肿、不花哨、打开就能用。

### 🔢 基础计算器

加减乘除、百分比、退格重算，该有的都有，不该有的一个不塞。界面清爽，按键手感好，按错能回退，不让你从头再来。

### 📏 单位换算

长度、体积、时间、重量、面积，五大类几十种单位，**实时换算、一键互换**。

- 出国旅行：英尺转米、加仑转升，秒出结果
- 装修买房：平方米转亩、公顷转平方千米，一步到位
- 做饭烘焙：克转盎司、毫升转杯，不用来回切换 App

### 💰 个税计算

基于中国大陆综合所得年度口径，支持：

- 工资薪金 / 劳务报酬 / 两者混合
- 社保、公积金按比例或固定扣除
- 7 项专项附加扣除（子女教育、房贷利息、赡养老人等）
- 月度扣税明细 + 税后到手一览

**算得清每一分钱去哪了。**

### 🏠 房贷计算

买房人的必备工具：

- 商业贷款 / 公积金贷款 / 组合贷
- 等额本息 / 等额本金，一键对比
- 组合贷可分别设置两部分年限与利率
- 月供、总利息、总还款额一目了然

### ⏱ 秒表计时

毫秒级精度，开始 / 暂停 / 重置 / 计次，跑步、健身、开会计时都能用。

### ⚠️ 裁员赔偿金（新增）

职场人必备功能，按《劳动合同法》计算：

- **N** — 经济补偿金（协商解除 / 合同到期）
- **N+1** — 经济补偿金 + 代通知金（未提前 30 天通知）
- **2N** — 违法解除赔偿金（公司违法解除）
- 支持工作年限、月工资、奖金输入
- 可选当地社平工资，自动处理三倍封顶 + 12 年上限

**被裁了不知道能拿多少？算一下就知道。**
